# 따라치기 단계 안 파일 순서

- 날짜: 2026-11-17
- 참여: 사용자, Claude

## 배경

ddd 따라치기는 2장부터 Main을 먼저 고친다.
학생이 그대로 치면 Order, OrderService가 나올 때까지 오류가 난 채로 친다.
fix 때문인지 따라치기 스킬 문제인지 알아봤다.

## 핵심 논의

- 단계 안 파일 순서는 codealong.mjs의 rank 함수가 정한다
- rank는 React 파일 이름(components, pages, main.jsx, App.jsx)만 안다
- 자바 파일은 모두 같은 순위가 되어 알파벳 순서로 놓인다. Main이 Order보다 앞이다
- Main이 나오는 53단계 중 20단계에서 Main이 맨 앞이다
- fix는 project-setup의 .project와 .classpath만 건드렸다. 순서와 상관없다
- 이름 바꾸기와 패키지 옮기기 단계는 순서를 바꿔도 잠깐 오류가 난다

## 결론

- 원인은 fix가 아니라 따라치기 엔진의 순서 규칙이다
- 단계 안 파일 순서는 쓰는 쪽을 뒤로 둔다
- 파일 이름(확장자 뺀 것)이 다른 파일의 그 단계 끝 코드에 단어로 나오면 쓴다고 보고 위상 정렬한다
- 판단이 안 되거나 서로 쓰면 알파벳 순서로 둔다
- 이름 바꾸기와 패키지 옮기기의 잠깐 오류는 받아들인다. 단계 끝에 오류가 없으면 된다. check-follow --build가 이미 확인한다
