# 로드맵

강의: 온라인 주문으로 배우는 도메인 주도 설계(DDD)
목표: DDD를 이해하고, 문제를 발견하고, 코드로 고치며 해결한다
대상: DDD를 처음 배우는 사람
결과물: 주문, 결제, 배송, 취소가 되는 순수 자바 주문 프로그램

## 선수 지식

- 자바: 클래스, 인터페이스, enum, record, 예외
- 자바: 컬렉션(List, Map), 람다, 패키지

## 학습 목표

- 전술 설계: 엔티티, 값 객체, 애그리거트, 리포지터리, 팩토리, 서비스, 이벤트, 명세
- 전략 설계: 유비쿼터스 언어, 하위 도메인, 바운디드 컨텍스트, 컨텍스트 맵
- 구조와 일관성: 계층 구조, 의존성 역전, 낙관적 잠금, 동기 이벤트 처리
- 규칙을 어디에 둘지 고르기: 값 객체, 애그리거트, 도메인 서비스, 이벤트, 응용 서비스

## 진행 방식

- 따라치기: DDD 코드다. 학생이 직접 친다
- 붙여넣기: DDD가 아닌 기반 코드다. 완성본을 복사한다
- 문제가 적힌 장은 문제를 먼저 실행해 보고 고친다

## 미룬 것

- 화면과 HTTP API
- 주문 항목 빼기와 수량 바꾸기
- 없는 회원 번호로 주문 막기
- 배송비를 더한 총 결제 금액
- 재고가 모자란 주문 막기

## 하지 않는 것

- 헥사고날 아키텍처
- Spring, JPA 같은 프레임워크
- 실제 DB와 메시지 큐, 분산 시스템
- 배송 컨텍스트와 문자열 메시지 교환
- 외부 결제 연결, CQRS, 사가, 소켓 통신
- 이벤트 대기 목록과 나중에 따로 실행하는 처리 명령
- 이벤트 소싱
- 쿠폰, 장바구니, 알림, 반품과 환불
- 콘솔 입력 메뉴. Main은 코드에 적은 장면을 실행해 출력한다
- 회원 등급으로 무료 배송 정하기
- 상품과 회원의 버전, 비관적 잠금, 낙관적 잠금 실패 뒤 자동 재시도
- 돈 값 객체와 공유 커널. 금액은 int로 둔다
- 자바 모듈로 컨텍스트 사이 접근 막기
- 용어집을 컨텍스트마다 나누기
- 주문 취소 때 재고 복원. 이번 강의는 주문 접수 뒤 재고 감소만 다룬다
