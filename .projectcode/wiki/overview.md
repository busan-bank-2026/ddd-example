## 미룬 것

- 화면과 HTTP API: 장 정하지 않음
- 주문 항목 빼기와 수량 바꾸기: 장 정하지 않음
- 없는 회원 번호로 주문 막기: 장 정하지 않음
- 배송비를 더한 총 결제 금액: 장 정하지 않음
- 재고가 모자란 주문 막기: 장 정하지 않음

## 하지 않는 것
- 헥사고날 아키텍처
- Spring, JPA 같은 프레임워크
- 실제 DB와 메시지 큐, 분산 시스템
- 배송 컨텍스트와 문자열 메시지 교환
- 외부 결제 연결, CQRS, 사가, 소켓 통신
- 이벤트 대기 목록과 나중에 따로 실행하는 처리 명령
- 이벤트 소싱
- 쿠폰, 장바구니, 알림, 반품과 환불
- 콘솔 입력 메뉴. Main은 코드에 적은 장면을 실행해 출력한다
- 회원 등급으로 무료 배송 정하기
- 상품과 회원의 버전, 비관적 잠금, 낙관적 잠금 실패 뒤 자동 재시도
- 돈 값 객체와 공유 커널. 금액은 int로 둔다
- 자바 모듈로 컨텍스트 사이 접근 막기
- 용어집을 컨텍스트마다 나누기
- 주문 취소 때 재고 복원. 이번 강의는 주문 접수 뒤 재고 감소만 다룬다
