## 미룬 것
- 화면과 HTTP API: 장 정하지 않음
- 주문 하나에 상품 여러 개: order-aggregate 장
- 주문 저장과 번호로 찾기: order-repository 장
- 금액과 주소 검사: value-object 장

## 하지 않는 것
- 헥사고날 아키텍처
- Spring, JPA 같은 프레임워크
- 실제 메시지 큐 제품(Kafka, RabbitMQ)과 분산 시스템
- JSON
- 이벤트 소싱
- 쿠폰, 장바구니, 알림
- 콘솔 입력 메뉴. Main은 코드에 적은 장면을 실행해 출력한다
