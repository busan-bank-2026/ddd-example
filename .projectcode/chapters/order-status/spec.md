# order-status 주문 상태

종류: 기능
배울 것: 상태 전이

## 할 일
- S1 주문 상태는 주문 접수, 결제 완료, 배송 중, 취소 중 하나로 정해져 있고 출력에는 업무 말로 보여준다
- S2 결제, 배송, 취소는 주문이 지금 상태를 보고 정한다. 결제는 주문 접수에서만, 배송은 결제 완료에서만, 취소는 주문 접수나 결제 완료에서만 된다. 취소는 다른 상태로 바뀌지 않는다
- S3 바꿀 수 없는 상태로 바꾸라고 하면 지금 상태를 넣은 말로 거절한다. 예: 주문 접수인 주문은 배송할 수 없습니다
- S4 결제 완료인 주문을 다시 결제하면 거절한다
- S5 배송 중인 주문을 배송 완료하면 배송 완료가 된다. 배송 완료인 주문은 다른 상태로 바뀌지 않는다
- S6 용어집에 주문 상태, 배송 완료하기, 배송 완료를 더하고 상태마다 코드 이름을 적는다

## 실행 결과
===== 주문 상태 =====

[결제하고 배송하기]
주문 상태: 주문 접수 -> 결제 완료
주문 상태: 결제 완료 -> 배송 중

[할 수 없는 일 시키기]
배송 중 취소: 배송 중인 주문은 취소할 수 없습니다
결제 없이 배송: 주문 접수인 주문은 배송할 수 없습니다

[두 번 결제하기]
두 번 결제: 결제 완료인 주문은 결제할 수 없습니다

[배송 완료하기]
주문 상태: 배송 중 -> 배송 완료

## 흐름
상태를 한 묶음으로 정하기 -> 결제, 배송, 취소가 지금 상태를 보고 정하기 -> 두 번 결제 거절 -> 배송 완료 더하기

## 안 하는 것
- 반품과 환불: 안 만듦
- 주문 저장과 번호로 찾기: order-repository 장
