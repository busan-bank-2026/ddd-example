# order-status 주문 상태

종류: 기능
배울 것: 상태 전이

## 할 일
- S1 주문 상태는 주문 접수, 결제 완료, 배송 중, 취소 중 하나로 정해져 있고 출력에는 업무 말로 보여준다
- S2 상태마다 바뀔 수 있는 다음 상태가 정해져 있다. 주문 접수는 결제 완료나 취소로, 결제 완료는 배송 중이나 취소로만 바뀐다. 취소는 다른 상태로 바뀌지 않는다
- S3 바꿀 수 없는 상태로 바꾸라고 하면 지금 상태를 넣은 말로 거절한다. 예: 주문 접수인 주문은 배송할 수 없습니다
- S4 결제 완료인 주문을 다시 결제하면 거절한다
- S5 배송 중인 주문을 배송 완료하면 배송 완료가 된다. 배송 완료인 주문은 다른 상태로 바뀌지 않는다
- S6 용어집에 주문 상태, 배송 완료하기, 배송 완료를 더하고 상태마다 코드 이름을 적는다

## 실행 결과
온라인 주문 프로그램을 시작합니다
주문: 1번, 김철수, 31000원, 주문 접수
주문 항목: 자바 책 2개, 30000원
주문 항목: 볼펜 1개, 1000원
결제: 결제 완료
배송: 배송 중
취소: 배송 중인 주문은 취소할 수 없습니다
결제 없이 배송: 주문 접수인 주문은 배송할 수 없습니다
음수 금액 주문: 금액은 0원 이상이어야 합니다
빈 주소 주문: 배송 주소를 입력해야 합니다
항목 더하기: 항목 3개, 주문 금액 41000원
결제 뒤 항목 더하기: 주문 접수인 주문에만 항목을 더할 수 있습니다
빈 주문: 주문 항목이 하나 이상 있어야 합니다
0개 항목 주문: 수량은 1개 이상이어야 합니다
두 번 결제: 결제 완료인 주문은 결제할 수 없습니다
배송 완료: 배송 완료

## 흐름
상태를 한 묶음으로 정하기 -> 상태마다 다음 상태 정하기 -> 결제, 배송, 취소가 그 규칙으로 확인 -> 두 번 결제 거절 -> 배송 완료 더하기

## 안 하는 것
- 반품과 환불: 안 만듦
- 주문 저장과 번호로 찾기: order-repository 장
