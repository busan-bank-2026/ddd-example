# value-object 돈과 주소

종류: 리팩터
배울 것: 값 객체, 불변
보여 줄 문제: 음수 금액 주문이 만들어진다

## 할 일
- S1 가격을 음수로 주문하면 음수 금액 주문이 그대로 만들어지는 문제를 실행해 보여준다
- S2 돈은 0원 이상이다. 음수 금액으로 돈을 만들면 거절한다
- S3 돈에 수량을 곱하거나 돈을 더하면 새 돈을 돌려주고 원래 돈은 그대로다. 금액이 같으면 같은 돈이다
- S4 주문의 가격과 주문 금액은 돈이다. 음수 가격으로 주문하면 주문이 만들어지지 않고 거절 메시지를 보여준다
- S5 배송 주소는 비어 있을 수 없다. 글자가 같으면 같은 주소다. 빈 주소로 주문하면 거절 메시지를 보여준다
- S6 용어집에 돈과 주소를 더한다

## 실행 결과
문제를 보여줄 때 (S1)
음수 금액 주문: -30000원

고친 뒤
온라인 주문 프로그램을 시작합니다
주문: 1번, 김철수, 자바 책 2개, 30000원, 주문 접수
결제: 결제 완료
배송: 배송 중
취소: 배송 중인 주문은 취소할 수 없습니다
결제 없이 배송: 결제하지 않은 주문은 배송할 수 없습니다
음수 금액 주문: 금액은 0원 이상이어야 합니다
빈 주소 주문: 배송 주소를 입력해야 합니다

## 흐름
문제 장면 실행 -> 금액을 돈으로 바꾸기 -> 같은 장면이 거절됨 -> 주소를 주소로 바꾸기 -> 빈 주소가 거절됨

## 그대로인 것
- 결제, 배송, 취소 규칙과 예외 메시지는 바뀌지 않는다
- 주문은 주문 번호로 알아본다. 돈과 주소는 값으로 알아본다
- 주문하기에 넘기는 값은 그대로 가격 숫자와 주소 글자다
- 상태는 글자 그대로 둔다. 상태 전이는 order-status 장이다
- 주문 하나에 상품 하나다. 여러 상품은 order-aggregate 장이다
