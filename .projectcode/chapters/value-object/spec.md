# value-object 주소

종류: 리팩터
배울 것: 값 객체, 불변
보여 줄 문제: 빈 주소 주문이 만들어진다

## 할 일
- S1 빈 주소로 주문하면 받을 곳 없는 주문이 그대로 만들어지는 문제를 실행해 보여준다
- S2 배송 주소는 비어 있을 수 없다. 빈 주소로 주소를 만들면 거절한다
- S3 글자가 같으면 같은 주소다. 주소는 만든 뒤 바꿀 수 없다
- S4 주문의 배송 주소는 주소다. 빈 주소로 주문하면 주문이 만들어지지 않고 거절 메시지를 보여준다
- S5 용어집에 주소를 더한다

## 실행 결과
문제를 보여줄 때 (S1)
===== 주소 =====

[주소로 주문하기]
주문: 1번 주문, 배송 주소 서울시 강남구

[빈 주소로 주문하기]
빈 주소 주문: 2번 주문, 주문 접수

고친 뒤
===== 주소 =====

[주소로 주문하기]
주문: 1번 주문, 배송 주소 서울시 강남구

[빈 주소로 주문하기]
빈 주소 주문: 배송 주소를 입력해야 합니다

## 흐름
문제 장면 실행 -> 주소를 주소 값 객체로 바꾸기 -> 같은 장면이 거절됨

## 그대로인 것
- 결제, 배송, 취소 규칙과 예외 메시지는 바뀌지 않는다
- 주문은 주문 번호로 알아본다. 주소는 값으로 알아본다
- 금액은 int 그대로다. 주문이 가격 곱하기 수량으로 계산한다
- 주문하기에 넘기는 값은 그대로 가격 숫자와 주소 글자다
- Main은 ===== 주소 ===== 아래에 이 장의 장면만 찍는다
- 상태는 글자 그대로 둔다. 상태 전이는 order-status 장이다
- 주문 하나에 상품 하나다. 여러 상품은 order-aggregate 장이다
