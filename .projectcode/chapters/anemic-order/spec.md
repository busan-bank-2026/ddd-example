# anemic-order 빈약한 주문

종류: 기능
배울 것: 규칙이 서비스에 흩어진 모델

## 할 일
- S1 주문자 이름, 상품 이름, 가격, 수량, 배송 주소로 주문을 만들면 주문 금액은 가격 곱하기 수량이고 상태는 주문 접수다
- S2 주문 접수인 주문을 결제하면 결제 완료가 된다
- S3 결제 완료인 주문을 배송하면 배송 중이 된다
- S4 결제하지 않은 주문을 배송하면 거절한다
- S5 배송 전인 주문을 취소하면 취소가 된다
- S6 배송 중인 주문을 취소하면 거절한다
- S7 프로그램을 실행하면 주문부터 취소 시도까지 장면을 콘솔에 보여준다

## 실행 결과
실행: 이클립스에서 Main을 Run
출력:
온라인 주문 프로그램을 시작합니다
주문: 김철수, 자바 책 2개, 30000원, 주문 접수
결제: 결제 완료
배송: 배송 중
취소: 배송 중인 주문은 취소할 수 없습니다

## 흐름
주문 만들기 -> 결제 -> 배송 -> 취소 시도 -> 거절

## 안 하는 것
- 주문 하나에 상품 여러 개: order-aggregate 장
- 주문 저장과 번호로 찾기: order-repository 장
- 금액과 주소 검사: value-object 장
- 콘솔 입력 메뉴: 안 만듦
