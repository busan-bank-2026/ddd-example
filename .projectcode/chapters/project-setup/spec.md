# project-setup 프로젝트 뼈대

종류: 기능
배울 것: 폴더 구조, 이클립스 실행

## 할 일
- S1 프로그램을 실행하면 콘솔에 시작 글을 보여준다
- S2 이클립스에서 ddd 폴더를 프로젝트로 열고 Main을 실행할 수 있다
- S3 테스트 명령을 실행하면 행동 테스트 결과를 보여준다

## 실행 결과
실행: java -cp bin ddd.Main
출력:
온라인 주문 프로그램을 시작합니다

테스트 실행: ddd 폴더에서 contract.md의 테스트 명령
출력: 3 tests successful

## 흐름
ddd 폴더 열기 -> Main 실행 -> 콘솔에 시작 글 -> 테스트 실행 -> 성공 결과

## 안 하는 것
- 콘솔 입력 메뉴: 안 만듦
- 주문 코드: anemic-order 장
