# free-shipping 무료 배송 조건

종류: 기능
배울 것: 명세

## 할 일
- S1 무료 배송 명세는 주문을 받아 무료 배송인지 참 거짓으로만 답한다. 결제 금액이 50000원 이상이면 참, 아니면 거짓이다. 명세는 도메인 계층에 두고, 칸이 없고, 주문을 바꾸지 않는다
- S2 주문은 배송비를 가진다. 무료 배송 명세를 만족하면 0원, 아니면 3000원이다. Main이 30000원 주문과 60000원 주문의 배송비를 보여준다
- S3 배송 주소가 제주인 주문은 결제 금액이 50000원 이상이어도 무료 배송이 아니다. 무료 배송 명세는 무료 배송 금액 명세와 무료 배송 지역 명세를 and로 묶어 만든다. Main이 6만원 주문의 서울과 제주 배송비를 보여준다
- S4 용어집에 주문 명세, 무료 배송 명세, 무료 배송 금액 명세, 무료 배송 지역 명세, 배송비를 더한다

## 실행 결과
===== 무료 배송 조건 =====

[결제 금액으로 배송비 정하기]
30000원 주문 배송비: 3000원
60000원 주문 배송비: 0원

[제주 주소는 무료 배송에서 빼기]
서울시 마포구 60000원 주문 배송비: 0원
제주시 연동 60000원 주문 배송비: 3000원

## 흐름
배송비 묻기 -> 주문이 무료 배송 명세에게 묻기 -> 금액 명세 and 지역 명세 -> 참이면 0원, 거짓이면 3000원

## 그대로인 것
- 할인 정책, 주문 금액, 할인 금액, 결제 금액은 그대로다
- 주문 응용 서비스는 바뀌지 않는다. 배송비는 주문이 명세에게 물어 정한다
- 명세는 참 거짓만 답한다. 0원이나 3000원 같은 돈은 주문이 정한다

## 안 하는 것
- 배송비를 결제 금액에 더한 총 결제 금액: 미룸. 결제 금액은 무료 배송을 가르는 기준이라 상품값만 담는다
- 회원 등급으로 무료 배송 정하기: 안 만듦. 주문은 회원을 번호로만 가리켜서 주문 하나를 받는 명세로는 등급을 물을 수 없다
