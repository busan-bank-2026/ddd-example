# free-shipping 무료 배송 조건

종류: 기능
배울 것: 명세

## 할 일
- S1 무료 배송 명세는 주문을 받아 무료 배송인지 참 거짓으로만 답한다. 결제 금액이 50000원 이상이면 참, 아니면 거짓이다. 명세는 도메인 계층에 두고, 칸이 없고, 주문을 바꾸지 않는다
- S2 주문은 배송비를 가진다. 무료 배송 명세를 만족하면 0원, 아니면 3000원이다. Main이 첫 주문의 할인 줄 다음에 배송비를 보여준다
- S3 배송 주소가 제주인 주문은 결제 금액이 50000원 이상이어도 무료 배송이 아니다. 무료 배송 명세는 무료 배송 금액 명세와 무료 배송 지역 명세를 and로 묶어 만든다. Main이 6만원 주문의 서울과 제주 배송비를 보여준다
- S4 용어집에 주문 명세, 무료 배송 명세, 무료 배송 금액 명세, 무료 배송 지역 명세, 배송비를 더한다

## 실행 결과
온라인 주문 프로그램을 시작합니다
주문: 1번, 김철수, 31000원, 주문 접수
주문 항목: 자바 책 2개, 30000원
주문 항목: 볼펜 1개, 1000원
결제: 결제 완료
할인: VIP 3100원, 결제 금액 27900원
배송비: 3000원
배송: 배송 중
취소: 배송 중인 주문은 취소할 수 없습니다
결제 없이 배송: 주문 접수인 주문은 배송할 수 없습니다
음수 금액 주문: 금액은 0원 이상이어야 합니다
빈 주소 주문: 배송 주소를 입력해야 합니다
항목 더하기: 항목 3개, 주문 금액 41000원
결제 뒤 항목 더하기: 주문 접수인 주문에만 항목을 더할 수 있습니다
빈 주문: 주문 항목이 하나 이상 있어야 합니다
0개 항목 주문: 수량은 1개 이상이어야 합니다
두 번 결제: 결제 완료인 주문은 결제할 수 없습니다
배송 완료: 배송 완료
없는 주문 결제: 주문이 없습니다
없는 상품 주문: 상품이 없습니다
저장 안 한 취소: 주문 접수
6만원 주문 배송비: 서울 0원, 제주 3000원
가격 바뀐 뒤: 1번 상품 18000원, 주문 항목 15000원, 주문 금액 31000원

## 흐름
배송비 묻기 -> 주문이 무료 배송 명세에게 묻기 -> 금액 명세 and 지역 명세 -> 참이면 0원, 거짓이면 3000원

## 그대로인 것
- 앞 장 출력 스물한 줄은 바뀌지 않는다. 할인 줄 다음에 배송비 줄, 가격 바뀐 뒤 줄 앞에 6만원 주문 줄을 더한다
- 할인 정책, 주문 금액, 할인 금액, 결제 금액은 그대로다
- 주문 응용 서비스는 바뀌지 않는다. 배송비는 주문이 명세에게 물어 정한다
- 명세는 참 거짓만 답한다. 0원이나 3000원 같은 돈은 주문이 정한다

## 안 하는 것
- 배송비를 결제 금액에 더한 총 결제 금액: 미룸. 결제 금액은 무료 배송을 가르는 기준이라 상품값만 담는다
- 회원 등급으로 무료 배송 정하기: 안 만듦. 주문은 회원을 번호로만 가리켜서 주문 하나를 받는 명세로는 등급을 물을 수 없다
