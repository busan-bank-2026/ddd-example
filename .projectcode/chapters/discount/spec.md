# discount 회원 등급 할인

종류: 기능
배울 것: 도메인 서비스

## 할 일
- S1 회원은 회원 번호, 이름과 함께 회원 등급을 가진다. 등급은 일반과 VIP 둘이다. Main은 김철수를 VIP로, 이영희를 일반으로 저장하고 두 회원의 등급을 보여준다
- S2 할인 정책은 회원과 주문을 받아 할인 금액을 계산한다. VIP는 주문 금액의 10%, 일반은 0원이다. 할인 정책은 도메인 계층에 두고, 저장소를 쓰지 않고, 주문을 바꾸지 않는다
- S3 주문은 결제할 때 할인 금액을 받아 기억한다. 결제 금액은 주문 금액에서 할인 금액을 뺀 금액이다. 결제 전 할인 금액은 0원이다
- S4 주문 응용 서비스는 결제하기에서 주문을 꺼내고, 회원을 찾고, 할인 정책에게 할인 금액을 계산하게 하고, 주문에게 결제를 시키고, 저장한다. Main이 VIP 회원과 일반 회원이 같은 상품을 주문하고 결제한 결제 금액과 할인 금액을 보여준다
- S5 용어집에 회원 등급, 일반, VIP, 할인 정책, 할인 금액, 결제 금액을 더하고 회원의 뜻에 회원 등급을 넣는다

## 실행 결과
===== 회원 등급 할인 =====

[회원 등급 정하기]
김철수 회원 등급: VIP
이영희 회원 등급: BASIC

[할인 정책으로 결제하기]
김철수 VIP 결제 금액: 31000원 -> 27900원, 할인 3100원
이영희 BASIC 결제 금액: 31000원 -> 31000원, 할인 0원

## 흐름
결제하기 -> 주문 꺼내기 -> 주문의 회원 번호로 회원 찾기 -> 할인 정책이 할인 금액 계산 -> 주문이 할인 금액을 받아 결제 완료 -> 주문 저장

## 그대로인 것
- 주문 금액은 할인 전 금액 그대로다. 두 주문 모두 31000원이다
- 주문하기와 주문 항목 더하기는 회원을 찾지 않는다
- 주문, 주문 항목, 주소, 주문 상태의 앞 장 규칙은 그대로다

## 안 하는 것
- 없는 회원 번호로 주문 막기: 미룸. 결제하기에서 회원을 못 찾으면 업무 말 없이 멈춘다
- 등급별 할인율을 바꾸는 설정과 등급 바꾸기: 안 만듦
- 배송비: free-shipping 장

## 14장과 비교
- 할인 정책은 회원과 주문으로 할인 금액을 계산한다
- 무료 배송 명세는 주문이 조건을 만족하는지 참 거짓으로 답한다
- 무료 배송 기준은 할인 뒤 결제 금액이다
