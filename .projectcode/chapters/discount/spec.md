# discount 회원 등급 할인

종류: 기능
배울 것: 도메인 서비스

## 할 일
- S1 회원은 회원 번호, 이름과 함께 회원 등급을 가진다. 등급은 일반과 VIP 둘이다. Main은 김철수를 VIP로, 이영희를 일반으로 저장하고, 앞 장 출력 스무 줄은 그대로다
- S2 할인 정책은 회원과 주문을 받아 할인 금액을 계산한다. VIP는 주문 금액의 10%, 일반은 0원이다. 할인 정책은 도메인 계층에 두고, 저장소를 쓰지 않고, 주문을 바꾸지 않는다
- S3 주문은 결제할 때 할인 금액을 받아 기억한다. 결제 금액은 주문 금액에서 할인 금액을 뺀 금액이다. 결제 전 할인 금액은 0원이다
- S4 주문 응용 서비스는 결제하기에서 주문을 꺼내고, 회원을 찾고, 할인 정책에게 할인 금액을 계산하게 하고, 주문에게 결제를 시키고, 저장한다. Main이 첫 주문의 할인 장면을 보여준다
- S5 용어집에 회원 등급, 일반, VIP, 할인 정책, 할인 금액, 결제 금액을 더하고 회원의 뜻에 회원 등급을 넣는다

## 실행 결과
온라인 주문 프로그램을 시작합니다
주문: 1번, 김철수, 31000원, 주문 접수
주문 항목: 자바 책 2개, 30000원
주문 항목: 볼펜 1개, 1000원
결제: 결제 완료
할인: VIP 3100원, 결제 금액 27900원
배송: 배송 중
취소: 배송 중인 주문은 취소할 수 없습니다
결제 없이 배송: 주문 접수인 주문은 배송할 수 없습니다
음수 금액 주문: 금액은 0원 이상이어야 합니다
빈 주소 주문: 배송 주소를 입력해야 합니다
항목 더하기: 항목 3개, 주문 금액 41000원
결제 뒤 항목 더하기: 주문 접수인 주문에만 항목을 더할 수 있습니다
빈 주문: 주문 항목이 하나 이상 있어야 합니다
0개 항목 주문: 수량은 1개 이상이어야 합니다
두 번 결제: 결제 완료인 주문은 결제할 수 없습니다
배송 완료: 배송 완료
없는 주문 결제: 주문이 없습니다
없는 상품 주문: 상품이 없습니다
저장 안 한 취소: 주문 접수
가격 바뀐 뒤: 1번 상품 18000원, 주문 항목 15000원, 주문 금액 31000원

## 흐름
결제하기 -> 주문 꺼내기 -> 주문의 회원 번호로 회원 찾기 -> 할인 정책이 할인 금액 계산 -> 주문이 할인 금액을 받아 결제 완료 -> 주문 저장

## 그대로인 것
- 앞 장 출력 스무 줄은 바뀌지 않는다. 결제 줄 다음에 할인 줄 하나만 더한다
- 주문 금액은 할인 전 금액 그대로다. 주문 줄의 31000원도 그대로다
- 주문하기와 주문 항목 더하기는 회원을 찾지 않는다
- 주문, 주문 항목, 주소, 주문 상태의 앞 장 규칙은 그대로다

## 안 하는 것
- 없는 회원 번호로 주문 막기: 미룸. 결제하기에서 회원을 못 찾으면 업무 말 없이 멈춘다
- 등급별 할인율을 바꾸는 설정과 등급 바꾸기: 안 만듦
- 배송비: free-shipping 장
