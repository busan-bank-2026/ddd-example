# order-repository 주문 저장소

종류: 기능
배울 것: 리포지터리

## 할 일
- S1 주문 저장소에 주문을 저장하고 주문 번호로 다시 꺼낼 수 있다. 없는 번호로 찾으면 빈 결과를 돌려준다
- S2 주문 저장소는 저장할 때와 꺼낼 때 복사본을 쓴다. 꺼낸 주문을 바꿔도 다시 저장하기 전에는 저장소의 주문이 그대로다
- S3 주문하기는 주문을 주문 저장소에 저장하고 주문 번호를 돌려준다
- S4 결제하기, 배송하기, 배송 완료하기, 주문 취소하기, 주문 항목 더하기는 주문 번호를 받아 저장소에서 주문을 꺼내 주문에게 시키고 다시 저장한다
- S5 없는 주문 번호로 결제하면 주문이 없습니다로 거절한다
- S6 용어집에 주문 저장소, 저장하기, 주문 번호로 찾기를 더한다

## 실행 결과
온라인 주문 프로그램을 시작합니다
주문: 1번, 김철수, 31000원, 주문 접수
주문 항목: 자바 책 2개, 30000원
주문 항목: 볼펜 1개, 1000원
결제: 결제 완료
배송: 배송 중
취소: 배송 중인 주문은 취소할 수 없습니다
결제 없이 배송: 주문 접수인 주문은 배송할 수 없습니다
음수 금액 주문: 금액은 0원 이상이어야 합니다
빈 주소 주문: 배송 주소를 입력해야 합니다
항목 더하기: 항목 3개, 주문 금액 41000원
결제 뒤 항목 더하기: 주문 접수인 주문에만 항목을 더할 수 있습니다
빈 주문: 주문 항목이 하나 이상 있어야 합니다
0개 항목 주문: 수량은 1개 이상이어야 합니다
두 번 결제: 결제 완료인 주문은 결제할 수 없습니다
배송 완료: 배송 완료
없는 주문 결제: 주문이 없습니다
저장 안 한 취소: 주문 접수

## 흐름
주문하기 -> 저장소에 저장하고 주문 번호 받기 -> 주문 번호로 꺼내기 -> 주문에게 시키기 -> 다시 저장하기

## 안 하는 것
- 주문 목록 전체 꺼내기: order-query 장
- 주문 지우기: 안 만듦. 주문은 지우지 않고 취소한다
