# payment-acl 외부 결제 연결

종류: 기능
배울 것: 부패 방지 계층, 컨텍스트 맵

## 할 일
- S1 외부 결제 모듈은 우리 말과 다른 모양으로 말한다. 가게 키와 원 단위 정수 금액을 받아 승인이면 0000, 10만 원을 넘으면 E101, 가게 키가 틀리면 E201 코드 글자를 돌려준다. 외부 모듈은 ddd 밖 묶음에 둔다. Main은 27900원과 108000원을 직접 맡겨 받은 코드 글자를 보여준다
- S2 주문 컨텍스트는 결제를 우리 말로 정한다. 결제 창구는 돈을 받아 결제 결과를 돌려준다. 결제 결과는 승인인지와 거절 이유를 가진다. 주문 도메인과 응용 계층은 외부 결제 모듈을 모른다
- S3 결제 어댑터는 결제 창구를 구현한다. 돈을 원 단위 정수로 바꾸고 가게 키를 붙여 외부 모듈에 맡기고, 받은 코드 글자를 결제 결과로 번역한다. 0000은 승인, E101은 거절 이유 결제 한도를 넘었습니다, 다른 코드는 거절 이유 결제에 실패했습니다다
- S4 결제하기는 결제 금액을 결제 창구에 맡긴다. 승인이면 저장하고 결제 완료 메시지를 넘긴다. 거절이면 거절 이유로 결제를 거절하고, 주문은 주문 접수로 남고, 결제 완료 메시지도 없다. Main은 자바 책 6개 주문을 결제해 거절 이유와 주문 상태를 보여준다
- S5 용어집에 결제 창구, 결제 결과, 결제 어댑터를 더한다. 외부 모듈의 코드 글자와 가게 키는 용어집에 올리지 않는다
- S6 컨텍스트 맵에 부패 방지 계층 절을 더해 외부 결제 모듈의 말과 우리 말을 표로 잇고, 하위 도메인 표에 결제를, 컨텍스트 사이 표에 주문이 외부 결제를 결제 어댑터로 쓰는 줄을 더한다. 용어집에 부패 방지 계층을 더한다

## 실행 결과
온라인 주문 프로그램을 시작합니다
주문: 1번, 김철수, 31000원, 주문 접수
주문 항목: 자바 책 2개, 30000원
주문 항목: 볼펜 1개, 1000원
주문 뒤: 이벤트 1개, 자바 책 재고 10개
이벤트 처리 뒤: 자바 책 재고 8개
결제: 결제 완료
할인: VIP 3100원, 결제 금액 27900원
배송비: 3000원
배송: 배송 중
취소: 배송 중인 주문은 취소할 수 없습니다
결제 없이 배송: 주문 접수인 주문은 배송할 수 없습니다
음수 금액 주문: 금액은 0원 이상이어야 합니다
빈 주소 주문: 배송 주소를 입력해야 합니다
항목 더하기: 항목 3개, 주문 금액 41000원
결제 뒤 항목 더하기: 주문 접수인 주문에만 항목을 더할 수 있습니다
빈 주문: 주문 항목이 하나 이상 있어야 합니다
0개 항목 주문: 수량은 1개 이상이어야 합니다
두 번 결제: 결제 완료인 주문은 결제할 수 없습니다
배송 완료: 배송 완료
없는 주문 결제: 주문이 없습니다
없는 상품 주문: 상품이 없습니다
저장 안 한 취소: 주문 접수
6만원 주문 배송비: 서울 0원, 제주 3000원
가격 바뀐 뒤: 1번 상품 18000원, 주문 항목 15000원, 주문 금액 31000원
동시 수정: 다른 곳에서 먼저 바꾼 주문입니다
결제 완료 메시지: ORDER_PAID|orderId=1|address=서울시 강남구
결제 완료 메시지: ORDER_PAID|orderId=4|address=광주시 북구
배송 컨텍스트: 1번 주문, 서울시 강남구
외부 결제 응답: 27900원 0000, 108000원 E101
한도 넘은 결제: 결제 한도를 넘었습니다, 주문 접수

## 외부 말과 우리 말
| 외부 결제 모듈 | 주문 컨텍스트 |
|---|---|
| 가게 키 | 결제 어댑터만 안다 |
| 원 단위 정수 금액 | 돈 |
| 0000 | 승인 |
| E101 | 거절. 결제 한도를 넘었습니다 |
| 그 밖의 코드 | 거절. 결제에 실패했습니다 |

## 흐름
결제하기 -> 결제 창구에 결제 금액 맡김 -> 결제 어댑터가 외부 모듈에 원 단위 금액과 가게 키로 승인 요청 -> 코드 글자를 결제 결과로 번역 -> 승인이면 저장하고 결제 완료 메시지, 거절이면 거절 이유로 거절

## 그대로인 것
- 앞 장 출력 스물아홉 줄은 바뀌지 않는다. 마지막 줄 다음에 두 줄을 더한다
- 공개 호스트 서비스와 배송 컨텍스트는 그대로다

## 안 하는 것
- 결제가 거절되면 줄인 재고 되돌리기와 주문 취소: order-saga 장
- 외부 결제의 시간 초과와 다시 시도: 안 만듦
- 외부 결제로 환불하기: 안 만듦. 반품과 환불은 하지 않는다
