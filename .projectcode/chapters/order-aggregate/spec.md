# order-aggregate 주문과 주문 항목

종류: 기능
배울 것: 애그리거트, 루트, 불변식
보여 줄 문제: 항목을 직접 더하면 합계가 틀린다

## 할 일
- S1 주문 항목은 상품 이름, 가격, 수량을 갖고 항목 금액은 가격 곱하기 수량이다. 주문은 주문 항목 여러 개로 만들고 주문 금액은 항목 금액의 합이다
- S2 주문에서 꺼낸 항목 목록에 밖에서 항목을 더하면 주문 금액이 항목과 맞지 않는 문제를 실행해 보여준다
- S3 주문 밖에서는 주문의 항목 목록을 바꿀 수 없다
- S4 항목 더하기는 주문에게 시킨다. 항목을 더하면 주문 금액도 함께 바뀐다
- S5 주문 접수가 아닌 주문에는 항목을 더할 수 없다. 결제한 주문에 항목을 더하면 거절한다
- S6 주문은 항목이 하나 이상이어야 한다. 항목 없이 주문하면 거절한다
- S7 주문 항목의 가격은 0원 이상, 수량은 1개 이상이다. 음수 가격이나 0개 항목으로 주문하면 거절한다
- S8 용어집에 주문 항목, 항목 금액, 주문 항목 더하기를 더한다

## 실행 결과
문제를 보여줄 때 (S2)
===== 주문과 주문 항목 =====

[여러 항목으로 주문하기]
주문: 1번 주문, 주문 금액 31000원
주문 항목: 자바 책 2개, 30000원
주문 항목: 볼펜 1개, 1000원

[항목 더하기]
항목 수: 2개 -> 3개
주문 금액: 31000원 -> 31000원

고친 뒤
===== 주문과 주문 항목 =====

[여러 항목으로 주문하기]
주문: 1번 주문, 주문 금액 31000원
주문 항목: 자바 책 2개, 30000원
주문 항목: 볼펜 1개, 1000원

[항목 더하기]
항목 수: 2개 -> 3개
주문 금액: 31000원 -> 41000원

[결제 뒤 항목 더하기]
결제 뒤 항목 더하기: 주문 접수인 주문에만 항목을 더할 수 있습니다

[잘못된 주문하기]
빈 주문: 주문 항목이 하나 이상 있어야 합니다
음수 가격 주문: 가격은 0원 이상이어야 합니다
0개 항목 주문: 수량은 1개 이상이어야 합니다

## 흐름
여러 항목으로 주문 -> 꺼낸 목록에 항목 더하기 -> 합계가 틀림 -> 목록을 주문 안에 두기 -> 주문에게 항목 더하기 시키기 -> 합계가 맞음 -> 빈 주문, 음수 가격, 0개 항목 거절

## 안 하는 것
- 주문 항목 빼기와 수량 바꾸기: 미룸
- 주문 상태 묶음과 상태 전이: order-status 장
- 주문 저장과 번호로 찾기: order-repository 장
