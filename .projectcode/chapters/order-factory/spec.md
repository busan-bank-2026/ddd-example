# order-factory 상품으로 주문 항목 만들기

종류: 기능
배울 것: 팩토리

## 할 일
- S1 주문 항목 요청은 상품 번호와 수량만 담는다. 상품 이름과 가격은 요청에 넣지 않는다
- S2 주문 항목 팩토리는 상품 번호와 수량을 받아 상품 저장소에서 상품을 찾고, 그 상품의 이름과 지금 가격을 담은 주문 항목을 만든다. 팩토리는 도메인 계층에 둔다
- S3 주문 응용 서비스는 주문하기와 주문 항목 더하기에서 주문 항목 팩토리에게 주문 항목을 만들게 한다. Main은 팩토리를 만들어 주문 응용 서비스에 넘기고, 앞 장 출력 열아홉 줄은 그대로다
- S4 없는 상품 번호로 주문하거나 항목을 더하면 상품이 없습니다로 거절하고 아무것도 저장하지 않는다. Main이 없는 상품 주문 장면을 보여준다
- S5 용어집에 주문 항목 팩토리를 더하고 주문 항목 요청의 뜻을 상품 번호와 수량으로 바꾼다

## 실행 결과
온라인 주문 프로그램을 시작합니다
주문: 1번, 김철수, 31000원, 주문 접수
주문 항목: 자바 책 2개, 30000원
주문 항목: 볼펜 1개, 1000원
결제: 결제 완료
배송: 배송 중
취소: 배송 중인 주문은 취소할 수 없습니다
결제 없이 배송: 주문 접수인 주문은 배송할 수 없습니다
음수 금액 주문: 금액은 0원 이상이어야 합니다
빈 주소 주문: 배송 주소를 입력해야 합니다
항목 더하기: 항목 3개, 주문 금액 41000원
결제 뒤 항목 더하기: 주문 접수인 주문에만 항목을 더할 수 있습니다
빈 주문: 주문 항목이 하나 이상 있어야 합니다
0개 항목 주문: 수량은 1개 이상이어야 합니다
두 번 결제: 결제 완료인 주문은 결제할 수 없습니다
배송 완료: 배송 완료
없는 주문 결제: 주문이 없습니다
없는 상품 주문: 상품이 없습니다
저장 안 한 취소: 주문 접수
가격 바뀐 뒤: 1번 상품 18000원, 주문 항목 15000원, 주문 금액 31000원

## 흐름
상품 번호와 수량으로 주문하기 -> 팩토리가 상품 저장소에서 상품 찾기 -> 상품 이름과 지금 가격으로 주문 항목 만들기 -> 주문 저장

## 그대로인 것
- 앞 장 출력 열아홉 줄은 바뀌지 않는다. 명령에 넣는 값만 상품 번호와 수량으로 줄어든다
- 음수 금액 주문 장면은 가격을 명령에 넣을 수 없어서 음수 가격 상품을 저장하려다 거절되는 모양으로 바뀐다. 출력 글자는 그대로다
- 주문, 주문 항목, 주소, 주문 상태의 규칙은 그대로다
- 주문 번호는 지금처럼 주문 응용 서비스가 정한다

## 안 하는 것
- 없는 회원 번호로 주문 막기: 미룸
- 회원 등급: discount 장
- 상품 재고: order-events 장
