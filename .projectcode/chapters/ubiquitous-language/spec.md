# ubiquitous-language 업무 말로 이름 짓기

종류: 리팩터
배울 것: 유비쿼터스 언어

## 할 일
- S1 주문을 만드는 일을 업무 말인 주문하기로 부른다
- S2 결제 상태를 바꾸는 일을 결제하기로 부른다
- S3 배송 상태를 바꾸는 일을 배송하기로 부른다
- S4 주문을 지우는 일을 주문 취소하기로 부른다. 주문은 지워지지 않고 취소 상태가 된다
- S5 업무 말과 코드 이름을 나란히 적은 용어집을 학생 프로젝트에 둔다

## 용어집 예시
| 업무 말 | 코드 이름 | 뜻 |
|---|---|---|
| 주문 | Order | 고객이 상품을 사겠다고 한 요청 |
| 주문하기 | placeOrder | 주문자, 상품, 수량, 배송 주소로 주문을 접수한다 |
| 결제하기 | pay | 주문 금액을 치러 결제 완료가 된다 |
| 배송하기 | ship | 결제 완료인 주문을 보내 배송 중이 된다 |
| 주문 취소하기 | cancel | 배송 전 주문을 취소 상태로 둔다. 지우지 않는다 |
| 주문 금액 | totalPrice | 가격 곱하기 수량 |

## 흐름
업무 말 정하기 -> 용어집에 적기 -> 코드 이름 바꾸기 -> 같은 장면 실행

## 그대로인 것
- 실행 출력 다섯 줄은 바뀌지 않는다
- 규칙은 여전히 서비스에 있다. 규칙을 주문으로 옮기는 것은 rich-entity 장이다
- 주문의 칸 이름은 그대로 둔다
